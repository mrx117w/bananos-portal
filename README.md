# BANANOS Portal

Portal web para restaurante y bar con menú digital, promociones, solicitudes de música y panel de administración en Python y JavaScript.

## Funciones

- Menú digital y administración de productos.
- Promociones e imágenes.
- Solicitudes de música y persistencia en archivos JSON.

## Tecnologías

Python (biblioteca estándar), HTML, CSS, JavaScript, Docker y Nginx.

## Inicio local

```bash
docker compose up --build
```

http://localhost:8080

## Configuración y alcance

Incluye datos de demostración vacíos en lugar de pagos, solicitudes y registros reales. El panel administrativo de esta versión requiere revisar y añadir controles de acceso antes de exponer el servidor a Internet. Las fotografías y marcas requieren los derechos correspondientes para su reutilización.
